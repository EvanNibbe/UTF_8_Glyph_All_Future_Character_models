UTF-8 Glyph System For All Characters

In order to make sure that all future character glyphs that anyone would want to draw can be written within the UTF-8 standard. The final part of the UTF-8 shall be used (the alien language reserved code, as Dylan Beattie would say).
The first 8 bits to signify that this particular symbol shall be used is:
11111110
